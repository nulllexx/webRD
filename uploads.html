Skin uploads

Put a custom skin on your BakoSMP account. Uploads take effect the next time you join — if you are already online, rejoin to see it.

Your password is sent to the server, never stored here. It is how the server knows the skin is yours to change.

Upload a skin

Skins need to be in the server's own format. Convert a normal skin PNG with the SkinsRestorer generator, then upload the .customskin file it hands back.

Uploaded skins

Look up everything a player has on file. No password needed — the list is public, the skins themselves are not secret.
